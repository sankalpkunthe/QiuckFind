# QuickFind

A simple autocomplete and fuzzy search engine built using **Trie** and **Levenshtein distance (DP)**.
QuickFind provides fast search suggestions, typo-tolerant search, result ranking, and performance benchmarking.

## Features

- Trie-based autocomplete
- Fuzzy search using Levenshtein distance
- Typo tolerance (`sang` → `sing`)
- Result ranking
- Debounced search (Latency to avoid regular query)
- Supports 100,000+ words
- Search performance measurement
- Simple React frontend

## Tech Stack

- React (frontend)
- Node.js (backend)
- Express (backend)
- JavaScript (algorithms)
